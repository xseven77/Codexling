# 01 - 额度面板与展示

本章介绍额度数据在界面上的呈现：主窗口额度面板、重置券融合卡组、额度健康色与用量网页快捷入口。数据获取见 02 章。

---

## 1. Codex 额度快照结构

`CodexUsageSnapshot`（`UsageModels.swift:45-61`）是 Codex 账号额度的统一视图模型：

| 字段 | 含义 |
|---|---|
| `accountName / accountEmail / workspaceName / planName` | 账号与工作区标识、订阅档位（Plus/Pro…） |
| `shortWindow: UsageWindow?` | **5 小时限流窗口**（Codex 未暴露时为 nil，`:50-51`） |
| `weekly: UsageWindow` | 周维度限流窗口 |
| `credits: CreditBalance` | 积分余额（`balance` + `expiresAt`，`:25-28`） |
| `resetCoupons: [ResetCoupon]` | 限流重置券列表（名称/张数/过期时间/来源/发放信息/`status`/`resetType`，`:30-43`） |
| `subscriptionActiveUntilISO / subscriptionWillRenew` | 订阅到期日与是否自动续费（来自 `/backend-api/subscriptions`，`:58-60`） |
| `fetchedAt / refreshState / sourceURL` | 抓取时间、状态文案、来源 |

`primaryWindow`：5h 窗口可用则为主信号，否则回落周窗口（`:66-69`）。`UsageWindow`（`:5-25`）内含 used/total、重置时间等。

## 2. 额度面板（UsagePanel）

主窗口仪表盘内的额度卡片由 `UsagePanel` 渲染（`UsageViews.swift:153-409`）：

- **额度行 `QuotaRow`**（`:470`）：一行一个窗口（5 小时 / 周），左侧标签、右侧百分比与重置倒计时；配 `LiquidQuotaBar` 液态进度条（`:528`）。
- **重置券行 `CouponRow`**（`:497`）：显示券数与最近过期时间。
- **明细行 `DetailLine`** 与刷新状态行 `RefreshStatusLine`（`:552/:568`）：上次刷新时间、失败原因等。
- **背景与波纹**：`CodexChromeBackground`（`:409`）+ `CodexMaterialWave` 点击波纹（`:678-820`）；点卡片任意处泛起材料波纹，颜色按当前主题 ink 解析。
- 布局切换由 `UsagePanelLayout`（`:148`）定义，横/竖版仪表盘各自适配。

## 3. 重置券融合卡组（ResetCouponFusionViews）

`ResetCouponSummaryView`（`ResetCouponFusionViews.swift:10`）把 Codex 的 rate-limit reset credits 渲染成「时间轴轨道 + 发放卡片」融合视图（`ResetCouponFusionDeck`，`:88`）：

- 每张券按 `count` 展开成独立展示条目（`:21-27`）。
- 时间轴范围取所有券的发放/过期时间最小-最大（`timelineRange`，`:148-150`；日期解析 `ResetCouponDateParser`，`:531`）。
- 空态为虚线圆环 + 居中说明（`ResetCouponEmptyStateView`，`:42`）。
- 深浅主题分别调校（`isDark`，`:146`）。

## 4. 额度健康色（QuotaHealthLevel）

`QuotaHealthLevel`（`UsageModels.swift:406-479`）按剩余额度比例分级（green/yellow/red 等），驱动：

- 状态栏圆灯「跟随额度」模式（`StatusBarPetBackgroundColor.automatic.resolved(for:)`，`AppSettings.swift:137-143`）。
- 仪表盘连接卡边框、Gateway 账号角标、`ProviderBalanceIndicator`（`MultiAgentModels.swift:155`）。

## 5. 其他展示元素

- **账单快捷链接** `ChatGPTBillingCompactLink`（`UsageViews.swift:634`）：跳转 `https://chatgpt.com/codex/settings/usage`（`UsageActions.openUsagePage`，`AppDelegate.swift:118-122`）。
- **活动微光文字** `ActivityShimmerText`（`ActivityShimmerText.swift:4`）：agent 状态文案的流光效果，含 reduced-motion 分支（`ActivityShimmerMotion`，`:70`）。
- **分隔线** `CodexDivider`（`CodexDivider.swift:7`）：面板分节统一样式。
- **Toast**：手动刷新结果以 `RefreshToast` 横幅呈现成功/失败明细（`UsageModels.swift:224-267`）。
- **预览空态**：`forceEmptyForPreview`（`ResetCouponFusionViews.swift:13-14`）是维护者调试空态用的临时开关，改后需 `./rebuild_and_run.sh` 生效——普通用户忽略。
