重置券 UI · 概念方案

组件入口统一为 ResetCouponSummaryView，横版与竖版共用同一套 Swift 实现；选定方案后只改 CompanionDashboardViews.swift 内券相关子视图即可。下方每种方案均展示：0 张、1 张、2+ 张堆叠，并在 420px（横版内容区） 与 330px（竖版） 两种宽度下预览。

怎么选：回复方案字母（如「C + 用圆点分页」）或组合偏好即可。概念图里的点击切换已用简单脚本演示（仅 B/C/D/E 的多张态）。

方案 A极简一行 · 去掉票根形态

信息压成单行卡片，多张时用右侧箭头 + 圆点分页，不再占用 88pt 票根。竖版最省高度（56pt），和额度横条视觉语言一致。

  • 最干净，和当前「额度横条」同一 family
  • 来源 source 可放在副标题，不再挤在票根底部
  • 缺点：券的「收藏品」感较弱

方案 B光晕卡片 · 大号序号区

保留「这是一张券」的分区感，但去掉锯齿票、纸纹和旋转小票图标。右侧 72pt 为序号 +「下一张」，视觉重心更现代。

  • 绿色氛围和 Dashboard 的 mint 主题衔接自然
  • 序号放大，切换动机更明确
  • 高度 68pt，比现状 82pt 略矮

方案 C精简票根 2.0 · 进化现有设计

仍用虚线 Stub + 中间圆孔，但去掉左右边缘锯齿、纸纹、倾斜 ticket 图标；Stub 变窄（68pt），整体 68pt 高。改动最小、用户仍能认出「券」。

  • 与现有交互一致：点右侧 Stub 切换 + 涟漪
  • 解决「乱、旧、像打印纸」的主要观感问题
  • 推荐作为保守升级默认项

方案 D通行证色带 · 无 Stub

左侧 5px 绿色轨类似地铁/通行证；切换改为尾部文字按钮「下一张 (2/5)」。信息密度高，适合将来券名、来源更长的情况。

  • 完全不依赖 Custom Shape，SwiftUI 实现简单
  • 横竖版宽度变化时自动伸缩，无固定 Stub 宽度问题

方案 E整卡可点 · 角标堆叠
