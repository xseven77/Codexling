Codexling · 竖向布局完整设计方案

把主面板从「188pt 侧栏 + 内容列」的左右结构改成 330pt 单列竖版。本页不是效果图，而是按 CompanionDashboardView 的真实判断逐条还原：所有平时被条件隐藏的分支——空态、缺数据、多任务、报错、到期提醒——都在这里显式画出来，配色与文案直接取自 UsageViews.swift、UsageModels.swift、CodexActivity.swift。
